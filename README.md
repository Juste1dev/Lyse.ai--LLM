# Lyse.ai

Lyse.ai is an open-source language model project focused on training lightweight transformer-based models from scratch.

The project contains the model architecture, tokenizer, training pipeline, configurations and supporting tools.

## Model

**Lyse-67M**

* 67M parameters
* 32,000 token vocabulary
* 512 token context
* Transformer architecture
* Pre-training and supervised fine-tuning

## Model Weights

The training checkpoints and model files are hosted on Hugging Face:

**[Lyse-67M — Hugging Face](https://huggingface.co/Tonnyxu12312/Lyse-67M)**

## Status

Lyse.ai is currently under active development. The architecture, training process and model capabilities may change over time.
